# 3L Visual Direction

3L is not an image-heavy project by default.

Use images sparingly for things that genuinely benefit from a visual anchor: a cover, frontispiece, major location, rare character/location reference, or a major release moment.

There is no chapter-art quota and no automatic image pipeline. Missing art never blocks prose or audio publication.

Images are presentation assets, not story authority. If an image conflicts with current manuscript prose, the image is wrong.

For the current house aesthetic, character framing, grime/silhouette rules, text limits, and reference-image weighting, use `visual/STYLE_AUTHORITY.md`.

The public reader should remain complete and intentional with zero images present.
